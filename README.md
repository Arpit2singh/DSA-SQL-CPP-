## 🗂️ Topics Covered

- **Arrays & Two Pointers**: Two Sum, 4Sum, Next Permutation, Trapping Rain Water, Subarray Sum
- **Sliding Window & Strings**: Longest Substring Without Repeating Characters, Palindromic Substrings
- **Linked Lists**: Reverse Linked List, Remove Nth Node, Cycle Detection, LRU Cache
- **Trees & Binary Search Trees**: Maximum Depth, Diameter, Symmetric Tree, Vertical Order Traversal
- **Graphs**: Course Schedule (Topological Sort / Cycle Detection), Redundant Connection
- **Dynamic Programming**: 0/1 Knapsack, Coin Change I & II, Longest Common Subsequence, House Robber, Edit Distance
- **SQL / Database**: Joins (Left/Inner), Aggregations, Window Functions, Subqueries, Department Highest Salary

## 📂 Repository Structure

Each question is organized into its own dedicated folder containing:
- Solution source file (`.cpp`, `.java`, or `.sql`)
- Problem `README.md` with description, constraints, and test cases.
